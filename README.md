# 신사 이벤트 참여봇 V8

## 추가 기능

- 화면에 고정으로 붙던 제목·시간·조건 이모지 제거
- 이벤트별 관리자가 항목 이모지 직접 등록
- 이벤트 내용 별도 수정
- 참여 마감시간 설정
- 마감시간 경과 시 자동으로 이벤트 종료 처리
- 여러 이벤트 동시 등록·진행 유지
- 회원은 진행 중 이벤트 목록에서 선택
- 이벤트별 승인·거절·신청 현황 유지
- 기존 Railway 볼륨 DB 자동 마이그레이션

## 관리자 수정 항목

- 이벤트명
- 이벤트 내용
- 참가시간
- 참여 마감시간
- 참여조건
- 승인문구
- 거절문구
- 제목 이모지
- 내용 이모지
- 참가시간 이모지
- 마감시간 이모지
- 참여조건 이모지

프리미엄 이모지는 메시지 본문에 저장됩니다. 텔레그램 제한으로 버튼 글자에는 프리미엄 이모지를 넣을 수 없습니다.

## 마감시간 형식

```text
2026-07-31 23:30
```

마감시간을 제거하려면 `없음`을 입력하세요.
