# 신사 이벤트 참여봇 V7 다중 이벤트

- 여러 이벤트 동시 등록 및 동시 진행
- 회원은 진행 중 이벤트 목록에서 버튼으로 선택
- 이벤트별 사진 1~5장 인증 및 신청
- 이벤트별 승인·거절
- 관리자 전체 이벤트 목록
- 이벤트별 수정·시작·종료·삭제
- 이벤트별 승인대기·신청현황
- 모든 화면 뒤로가기
- 이벤트명·참가시간·참여조건·승인문구·거절문구 프리미엄 이모지 저장

Railway Variables:

```env
BOT_TOKEN=봇토큰
ADMIN_ID=관리자 숫자 ID
DB_FILE=/data/event_bot.db
```

Custom Start Command:

```text
python bot.py
```
