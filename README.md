# 신사 이벤트 참여봇 V10

기존 V8.2 이벤트 참여봇을 기준으로 그룹 공지/자동 시작·마감/인증방식/미디어 기능을 확장한 버전입니다.

## 추가/유지 기능
- 여러 이벤트 등록/관리
- 기존 이벤트명/내용/참가시간/참여조건/승인문구/거절문구 수정
- 일반 이모지 + 텔레그램 프리미엄 이모지
- 이벤트별 자동 시작시간/마감시간 (KST)
- 자동 시작 시 그룹방 EVENT OPEN 공지
- 자동 마감 시 그룹방 EVENT CLOSED 공지
- 이벤트별 시작공지/마감공지 ON/OFF
- 전체 그룹 시작공지/마감공지 ON/OFF
- 관리자 즉시 시작/마감 그룹 공지
- 대표 사진/GIF 등록
- 그룹 공지 대표 미디어 포함
- 그룹 공지 버튼에서 봇 개인채팅 이벤트 딥링크 연결
- 인증방식: 당일 채팅 / 당일 제휴 / 둘 다
- 인증사진 1~10장 (기본 최대 10장)
- 같은 이벤트 중복 신청 방지
- 관리자 승인/거절
- 거절사유 버튼 + 직접입력
- 내 신청 상태
- 승인 대기/통계
- 기존 SQLite DB 자동 컬럼 추가 방식으로 데이터 유지

## Railway Variables
```
BOT_TOKEN=봇파더 토큰
ADMIN_ID=관리자 텔레그램 숫자ID
DB_FILE=/data/event_bot.db
```

## Railway Volume
Railway에서 Volume을 추가하고 Mount Path를 `/data` 로 설정하세요.
DB_FILE은 `/data/event_bot.db` 로 두면 재배포 시 DB가 유지됩니다.

## 그룹 등록
1. 봇을 이벤트 공지를 올릴 그룹에 추가합니다.
2. 봇에게 메시지 전송 권한을 줍니다.
3. 관리자 계정으로 그 그룹에서 `/setgroup` 을 입력합니다.
4. 봇 개인채팅에서 `/admin` → `그룹/공지 설정`에서 등록 여부를 확인합니다.

## 이벤트 등록 순서
`/admin` → `이벤트 새로 등록` 후 이벤트 관리 화면에서 다음을 설정합니다.
- 이벤트명
- 내용
- 참가시간 문구
- 참여조건
- 자동 시작시간
- 마감시간
- 인증방식
- 대표 사진/GIF
- 승인문구/거절문구
- 이모지
- 그룹 공지 ON/OFF

자동 시작시간은 `2026-08-07 18:00` 같은 형식이며 한국시간 기준입니다.

## 자동 공지
스케줄러는 약 20초 간격으로 이벤트 시간을 확인합니다.
Railway 서버가 UTC여도 코드 내부에서 KST(+09:00) 기준으로 비교합니다.

## 주의
- Railway Replica는 1개만 실행하세요. 동일 토큰으로 polling 봇을 2개 띄우면 Conflict 오류가 납니다.
- 그룹에서 봇이 메시지를 보내려면 그룹의 메시지 전송 권한이 필요합니다.
- 기존 V8 DB는 삭제하지 않고 컬럼을 자동 추가합니다. 그래도 실제 배포 전 Railway Volume 백업을 권장합니다.


## V10 PREMIUM EMOJI 변경사항
이벤트 카드의 다음 7개 항목 앞 이모지를 관리자가 각각 설정할 수 있습니다.

- 이벤트명
- 이벤트 내용
- 참가시간
- 자동 시작
- 참여 마감시간
- 참여조건
- 인증방식

일반 이모지와 텔레그램 프리미엄 커스텀 이모지 모두 등록할 수 있습니다.
기존에 코드에 고정되어 있던 `⏰ 자동 시작`, `📸 인증방식` 일반 이모지는 제거했습니다.
기존 Railway Volume DB는 삭제하지 않으며 실행 시 `emoji_start`, `emoji_proof` 컬럼을 자동 추가합니다.


## V10 변경사항
- 관리자 홈의 `내 신청상태 버튼 이모지` 단독 메뉴를 제거했습니다.
- 관리자 홈에 `이모지 설정` 통합 메뉴를 추가했습니다.
- 통합 메뉴 안에서:
  1. 이벤트 항목 이모지 설정
  2. 내 신청상태 버튼 이모지
  를 함께 관리할 수 있습니다.
- 이벤트를 선택한 뒤 다음 7개 항목의 이모지를 각각 설정할 수 있습니다.
  - 이벤트명
  - 이벤트 내용
  - 참가시간
  - 자동 시작
  - 참여 마감시간
  - 참여조건
  - 인증방식
- 각 항목은 일반 이모지와 텔레그램 프리미엄 이모지를 지원합니다.
- 이벤트 이모지 설정 화면에서 `이모지 이벤트 목록`으로 바로 돌아갈 수 있습니다.


## V10 인증 방식 변경
- 회원이 이벤트 참여 시 `당일 채팅 / 당일 제휴`를 선택하는 단계가 삭제되었습니다.
- 참여 버튼을 누르면 바로 이미지 인증 단계로 이동합니다.
- 모든 이벤트의 인증 이미지는 최소 1장, 최대 5장입니다.
- 이미지 내용은 봇이 구분하지 않으며 관리자가 직접 확인합니다.
- 이벤트별 `인증안내 수정` 메뉴가 추가되었습니다.
- 인증안내 문구에는 일반 이모지와 텔레그램 프리미엄 이모지를 사용할 수 있습니다.
- `이모지 설정 > 인증안내 이모지`와 인증안내 문구를 함께 사용할 수 있습니다.
- 기존 DB는 삭제하지 않고 `proof_guide`, `proof_guide_html` 컬럼을 자동 추가합니다.
- 기존 이벤트의 max_photos 값도 실행 시 5장으로 자동 통일합니다.


## V10 변경사항
- 이벤트 관리 화면에 `시작공지 문구 수정`, `마감공지 문구 수정` 버튼 추가
- 이벤트별 공지 문구에 일반/프리미엄 이모지 저장 가능
- 시작공지 변수: `{title}`, `{start_at}`, `{deadline_at}`, `{conditions}`, `{proof_guide}`
- 마감공지 변수: `{title}`, `{deadline_at}`
- 시작시간 도달 시 KST 기준 자동 이벤트 시작
- 시작공지 ON이면 설정된 그룹에 자동 시작공지 발송
- 마감시간 도달 시 자동 이벤트 종료 및 신규 신청 차단
- 마감공지 ON이면 설정된 그룹에 자동 마감공지 발송
- 스케줄러는 약 20초 간격으로 확인
- 수동 종료한 이벤트가 예약 시작 조건 때문에 다시 살아나는 문제 방지
- 기존 DB는 삭제하지 않고 공지 문구 컬럼만 자동 추가


## V10 단일 그룹 운영 강화
- 그룹은 기존처럼 1개만 사용합니다.
- 시작 10분 전 예고공지 ON/OFF
- 10분 전 예고공지 문구 수정
- 시작공지 고정 ON/OFF
- 마감공지 고정 ON/OFF
- 예고공지 / 시작공지 / 마감공지 각각 별도 사진 또는 GIF 설정
- 이미 전송된 공지는 가능하면 삭제하지 않고 기존 메시지를 수정해서 반영
- 이벤트 종료 시 시작공지의 `이벤트 참여하기` 버튼 자동 제거
- Railway 재시작 등으로 시작/마감 시점을 놓쳐도 스케줄러가 상태와 공지를 자동 복구
- 마감시간 도달 시 이벤트를 자동 ended 처리하여 신규 신청 차단
- 스케줄러는 약 20초 간격으로 한국시간을 확인


## V11 SIMPLE
운영 화면을 다시 단순화했습니다.

관리자 이벤트 화면:
- 이벤트명 수정
- 내용 수정
- 이벤트 시간 설정
- 마감시간 설정
- 이벤트 조건 수정
- 공지 시작문구 수정
- 공지 종료문구 수정
- 이모지 설정
- 미리보기
- 승인 대기
- 이벤트 현황
- 이벤트 시작/종료
- 삭제

이모지 설정:
- 이벤트명
- 이벤트 내용
- 이벤트 시간
- 이벤트 조건
각 항목에 일반 이모지와 텔레그램 프리미엄 이모지를 등록할 수 있습니다.

자동 동작:
- 시작시간이 되면 이벤트 자동 시작
- 시작공지 ON 상태라면 등록된 단일 그룹에 자동 공지
- 마감시간이 되면 이벤트 자동 종료
- 종료 즉시 신규 신청 차단
- 마감공지 ON 상태라면 그룹에 종료 멘트 자동 발송
- Railway 재시작 후에도 놓친 시작/마감 상태를 다시 확인


## V11.1 대표 이미지/GIF 1~5개
- 이벤트마다 대표 사진/GIF를 최대 5개까지 등록할 수 있습니다.
- 사진과 GIF를 섞어서 등록 가능합니다.
- 이벤트 관리의 `대표 이미지/GIF`에서 여러 개를 연속으로 보낸 뒤 `등록 완료`를 누릅니다.
- 전체 삭제 후 다시 등록할 수 있습니다.
- 회원 이벤트 상세와 관리자 미리보기에서 대표미디어가 전부 표시됩니다.
- 시작시간에 그룹 자동공지가 올라갈 때 대표미디어도 함께 전송됩니다.
- 마감공지에는 종료 문구만 전송됩니다.
- 기존 단일 대표 이미지/GIF가 있으면 실행 시 자동 이전합니다.
