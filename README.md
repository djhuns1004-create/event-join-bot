# 신사 이벤트 참여봇 V9.4

기존 V8.2 이벤트 참여봇을 기준으로 그룹 공지/자동 시작·마감/인증방식/미디어 기능을 확장한 버전입니다.

## 추가/유지 기능
- 여러 이벤트 등록/관리
- 기존 이벤트명/내용/참가시간/참여조건/승인문구/거절문구 수정
- 일반 이모지 + 텔레그램 프리미엄 이모지
- 이벤트별 자동 시작시간/마감시간 (KST)
- 자동 시작 시 그룹방 EVENT OPEN 공지
- 자동 마감 시 그룹방 EVENT CLOSED 공지
- 이벤트별 시작공지/마감공지 ON/OFF
- 전체 그룹 시작공지/마감공지 ON/OFF
- 관리자 즉시 시작/마감 그룹 공지
- 대표 사진/GIF 등록
- 그룹 공지 대표 미디어 포함
- 그룹 공지 버튼에서 봇 개인채팅 이벤트 딥링크 연결
- 인증방식: 당일 채팅 / 당일 제휴 / 둘 다
- 인증사진 1~10장 (기본 최대 10장)
- 같은 이벤트 중복 신청 방지
- 관리자 승인/거절
- 거절사유 버튼 + 직접입력
- 내 신청 상태
- 승인 대기/통계
- 기존 SQLite DB 자동 컬럼 추가 방식으로 데이터 유지

## Railway Variables
```
BOT_TOKEN=봇파더 토큰
ADMIN_ID=관리자 텔레그램 숫자ID
DB_FILE=/data/event_bot.db
```

## Railway Volume
Railway에서 Volume을 추가하고 Mount Path를 `/data` 로 설정하세요.
DB_FILE은 `/data/event_bot.db` 로 두면 재배포 시 DB가 유지됩니다.

## 그룹 등록
1. 봇을 이벤트 공지를 올릴 그룹에 추가합니다.
2. 봇에게 메시지 전송 권한을 줍니다.
3. 관리자 계정으로 그 그룹에서 `/setgroup` 을 입력합니다.
4. 봇 개인채팅에서 `/admin` → `그룹/공지 설정`에서 등록 여부를 확인합니다.

## 이벤트 등록 순서
`/admin` → `이벤트 새로 등록` 후 이벤트 관리 화면에서 다음을 설정합니다.
- 이벤트명
- 내용
- 참가시간 문구
- 참여조건
- 자동 시작시간
- 마감시간
- 인증방식
- 대표 사진/GIF
- 승인문구/거절문구
- 이모지
- 그룹 공지 ON/OFF

자동 시작시간은 `2026-08-07 18:00` 같은 형식이며 한국시간 기준입니다.

## 자동 공지
스케줄러는 약 20초 간격으로 이벤트 시간을 확인합니다.
Railway 서버가 UTC여도 코드 내부에서 KST(+09:00) 기준으로 비교합니다.

## 주의
- Railway Replica는 1개만 실행하세요. 동일 토큰으로 polling 봇을 2개 띄우면 Conflict 오류가 납니다.
- 그룹에서 봇이 메시지를 보내려면 그룹의 메시지 전송 권한이 필요합니다.
- 기존 V8 DB는 삭제하지 않고 컬럼을 자동 추가합니다. 그래도 실제 배포 전 Railway Volume 백업을 권장합니다.


## V9.4 PREMIUM EMOJI 변경사항
이벤트 카드의 다음 7개 항목 앞 이모지를 관리자가 각각 설정할 수 있습니다.

- 이벤트명
- 이벤트 내용
- 참가시간
- 자동 시작
- 참여 마감시간
- 참여조건
- 인증방식

일반 이모지와 텔레그램 프리미엄 커스텀 이모지 모두 등록할 수 있습니다.
기존에 코드에 고정되어 있던 `⏰ 자동 시작`, `📸 인증방식` 일반 이모지는 제거했습니다.
기존 Railway Volume DB는 삭제하지 않으며 실행 시 `emoji_start`, `emoji_proof` 컬럼을 자동 추가합니다.
