# 신사 이벤트 참여봇 V8.1

## 변경사항

- 상단 안내를 한 줄로 정리
- `\n`이 문자로 표시되던 오류 수정
- 이벤트 버튼 앞 고정 이모지 제거
- 이벤트별 제목 이모지를 버튼에 적용
- `내 신청 상태` 버튼 이모지를 관리자 메뉴에서 별도 설정
- 기존 다중 이벤트, 마감시간, 승인·거절 기능 유지

## 텔레그램 제한

프리미엄 커스텀 이모지는 메시지 본문에는 표시되지만 인라인 버튼에는 표시할 수 없습니다.

버튼에는 일반 유니코드 이모지만 사용할 수 있습니다.

## 관리자

```text
/admin
→ 내 신청상태 버튼 이모지
```

이벤트 버튼은 각 이벤트의 `제목 이모지` 설정을 사용합니다.

## Railway

```env
BOT_TOKEN=봇토큰
ADMIN_ID=관리자 숫자 ID
DB_FILE=/data/event_bot.db
```

Custom Start Command:

```text
python bot.py
```
