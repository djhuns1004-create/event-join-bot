# 신사 이벤트 참여봇 V10

기존 V8.2 이벤트 참여봇을 기준으로 그룹 공지/자동 시작·마감/인증방식/미디어 기능을 확장한 버전입니다.

## 추가/유지 기능
- 여러 이벤트 등록/관리
- 기존 이벤트명/내용/참가시간/참여조건/승인문구/거절문구 수정
- 일반 이모지 + 텔레그램 프리미엄 이모지
- 이벤트별 자동 시작시간/마감시간 (KST)
- 자동 시작 시 그룹방 EVENT OPEN 공지
- 자동 마감 시 그룹방 EVENT CLOSED 공지
- 이벤트별 시작공지/마감공지 ON/OFF
- 전체 그룹 시작공지/마감공지 ON/OFF
- 관리자 즉시 시작/마감 그룹 공지
- 대표 사진/GIF 등록
- 그룹 공지 대표 미디어 포함
- 그룹 공지 버튼에서 봇 개인채팅 이벤트 딥링크 연결
- 인증방식: 당일 채팅 / 당일 제휴 / 둘 다
- 인증사진 1~10장 (기본 최대 10장)
- 같은 이벤트 중복 신청 방지
- 관리자 승인/거절
- 거절사유 버튼 + 직접입력
- 내 신청 상태
- 승인 대기/통계
- 기존 SQLite DB 자동 컬럼 추가 방식으로 데이터 유지

## Railway Variables
```
BOT_TOKEN=봇파더 토큰
ADMIN_ID=관리자 텔레그램 숫자ID
DB_FILE=/data/event_bot.db
```

## Railway Volume
Railway에서 Volume을 추가하고 Mount Path를 `/data` 로 설정하세요.
DB_FILE은 `/data/event_bot.db` 로 두면 재배포 시 DB가 유지됩니다.

## 그룹 등록
1. 봇을 이벤트 공지를 올릴 그룹에 추가합니다.
2. 봇에게 메시지 전송 권한을 줍니다.
3. 관리자 계정으로 그 그룹에서 `/setgroup` 을 입력합니다.
4. 봇 개인채팅에서 `/admin` → `그룹/공지 설정`에서 등록 여부를 확인합니다.

## 이벤트 등록 순서
`/admin` → `이벤트 새로 등록` 후 이벤트 관리 화면에서 다음을 설정합니다.
- 이벤트명
- 내용
- 참가시간 문구
- 참여조건
- 자동 시작시간
- 마감시간
- 인증방식
- 대표 사진/GIF
- 승인문구/거절문구
- 이모지
- 그룹 공지 ON/OFF

자동 시작시간은 `2026-08-07 18:00` 같은 형식이며 한국시간 기준입니다.

## 자동 공지
스케줄러는 약 20초 간격으로 이벤트 시간을 확인합니다.
Railway 서버가 UTC여도 코드 내부에서 KST(+09:00) 기준으로 비교합니다.

## 주의
- Railway Replica는 1개만 실행하세요. 동일 토큰으로 polling 봇을 2개 띄우면 Conflict 오류가 납니다.
- 그룹에서 봇이 메시지를 보내려면 그룹의 메시지 전송 권한이 필요합니다.
- 기존 V8 DB는 삭제하지 않고 컬럼을 자동 추가합니다. 그래도 실제 배포 전 Railway Volume 백업을 권장합니다.

## V10 인증 방식 변경
- 회원이 이벤트 참여 시 `당일 채팅 / 당일 제휴`를 선택하는 단계가 삭제되었습니다.
- 참여 버튼을 누르면 바로 이미지 인증 단계로 이동합니다.
- 모든 이벤트의 인증 이미지는 최소 1장, 최대 5장입니다.
- 이미지 내용은 봇이 구분하지 않으며 관리자가 직접 확인합니다.
- 이벤트별 `인증안내 수정` 메뉴가 추가되었습니다.
- 인증안내 문구에는 일반 이모지와 텔레그램 프리미엄 이모지를 사용할 수 있습니다.
- `이모지 설정 > 인증안내 이모지`와 인증안내 문구를 함께 사용할 수 있습니다.
- 기존 DB는 삭제하지 않고 `proof_guide`, `proof_guide_html` 컬럼을 자동 추가합니다.
- 기존 이벤트의 max_photos 값도 실행 시 5장으로 자동 통일합니다.

## V12 CLEAN FINAL
- 관리자 메인에서 `그룹/공지 설정` 메뉴를 제거했습니다.
- 그룹은 사용할 그룹에서 `/setgroup` 한 번만 실행하면 됩니다.

- 시작공지 문구와 종료공지 문구는 이벤트별로 직접 수정할 수 있습니다.
- 대표 이미지/GIF는 이벤트별 1~5개까지 등록할 수 있습니다.
- 이벤트명 / 내용 / 시간 / 조건 이모지는 일반 이모지와 텔레그램 프리미엄 이모지를 모두 지원합니다.
- 관리자 메뉴의 불필요한 고정 일반 이모티콘을 제거했습니다.


## V12.1 WAIT SCREEN
- 예약 이벤트는 시작시간 전까지 회원 화면에 표시하지 않습니다.
- 현재 진행중 이벤트가 없으면 `현재 참여할 수 있는 이벤트가 없습니다.` 대기화면과 `내 신청 상태` 버튼만 표시합니다.
- 시작시간이 되면 예약 이벤트가 자동으로 진행중으로 전환되고 회원 화면에 나타납니다.
- 동시에 설정된 그룹에 이벤트 시작공지가 자동 발송됩니다.
- 대기화면 제목 이모지는 관리자 `이모지 설정 > 대기화면 이모지`에서 일반/프리미엄 이모지로 변경 가능합니다.


## V12.2 회원 참여 승인 흐름
- 회원이 진행중 이벤트에서 `이 이벤트 참여` 버튼을 누르면 바로 인증 단계로 이동합니다.
- 회원은 인증 이미지를 최소 1장, 최대 5장까지 등록할 수 있습니다.
- 이미지 내용을 봇이 구분하지 않으며 이벤트 조건에 맞는 모든 캡처 이미지를 받을 수 있습니다.
- 인증 안내문은 이벤트 관리의 `참여 인증 안내`에서 직접 수정할 수 있습니다.
- 인증 안내 제목 앞 이모지는 `이모지 설정 > 인증안내 이모지`에서 일반/프리미엄 이모지로 설정할 수 있습니다.
- 회원이 `인증 제출`을 누르면 관리자에게 인증 이미지와 회원정보, 승인/거절 버튼이 전달됩니다.
- 관리자가 승인하면 회원에게 이벤트별 `승인 문구`가 자동 발송됩니다.
- 관리자가 거절하면 회원에게 이벤트별 `거절 문구`와 거절 사유가 자동 발송됩니다.
- 승인/거절 문구는 이벤트마다 직접 수정할 수 있습니다.
- 승인/거절 제목 이모지도 각각 일반/프리미엄 이모지로 설정할 수 있습니다.
- 같은 신청을 두 번 승인/거절할 수 없도록 기존 중복처리 방지를 유지합니다.


## V12.3 COMPACT UI
- 이벤트 카드의 구분선을 짧은 `━━━━━━━━━━━━` 형태로 변경했습니다.
- 제목과 구분선 사이의 불필요한 빈 줄을 줄였습니다.
- 이벤트 카드의 항목 간격을 정리해 전체 세로 길이를 줄였습니다.
- `이벤트 시간` 표시는 `진행기간`으로 통일했습니다.
- 시작일과 종료일이 같은 날짜라면 `2026.08.07 13:40 ~ 18:00`처럼 날짜를 한 번만 표시합니다.
- 이벤트 참여 / 목록 / 이벤트 관리 버튼에서 불필요한 고정 일반 이모티콘을 제거했습니다.
- 그룹 자동 시작공지도 동일한 컴팩트 카드 UI를 사용합니다.
- 그룹 종료공지는 제목 + 종료 문구만 간단히 표시합니다.
- 관리자에게 전달되는 참가 신청 카드도 회원정보와 인증사진 장수 중심으로 압축했습니다.
- 예약, 자동시작, 자동마감, 승인/거절, 대표미디어, 프리미엄 이모지 기능은 그대로 유지됩니다.


## V12.4 CONDITION ONLY
- `참여 인증 안내` 메뉴를 제거했습니다.
- 회원 인증 안내는 이벤트의 `이벤트 조건`을 그대로 사용합니다.
- 회원이 이벤트 참여를 누르면:
  1. 이벤트 조건 표시
  2. 인증 이미지 1~5장 등록
  3. 인증 제출
  순서로 진행됩니다.
- 이모지 설정에서도 `인증안내 이모지`를 제거했습니다.
- 이벤트명 / 내용 / 시간 / 조건 / 승인 / 거절 이모지만 관리합니다.
- 기존 DB의 proof_guide 관련 컬럼은 호환을 위해 남겨두지만 화면에서는 사용하지 않습니다.
- 승인/거절, 자동시작, 자동마감, 그룹공지, 대표미디어 1~5개 기능은 그대로 유지됩니다.


## V12.5 STRICT TIME
- 회원 참여 가능 시간을 엄격하게 검사합니다.
- `시작시간 <= 현재 한국시간 < 마감시간`일 때만 이벤트가 회원에게 표시됩니다.
- 시작시간 전에는 예약 이벤트가 `/start` 목록에 나오지 않습니다.
- 시작시간 전에는 예전에 받은 참여 버튼이나 딥링크를 눌러도 신청할 수 없습니다.
- 마감시간이 되면 즉시 신청이 차단됩니다.
- 인증사진을 올리는 중이더라도 마감시간이 지나면 추가 등록/제출할 수 없습니다.
- DB의 status 값이 잘못 남아 있어도 실제 시작/마감시간을 다시 확인하여 시간 밖 이벤트를 숨깁니다.
- 시작시간 또는 마감시간이 하나라도 비어 있으면 회원에게 공개하지 않습니다.
